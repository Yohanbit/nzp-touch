# NZP · Controles táctiles

Versión web de **Nazi Zombies: Portable** con controles táctiles. Proyecto no oficial basado en el juego de **NZ:P Team**.

## Jugar

**[Abrir el juego · v3.2.2](https://yohanbit.github.io/nzp-touch/?v=3.2.2&layout=5)**

Juega en horizontal. La primera carga descarga unos 100 MB. Toca la pantalla para activar el sonido.

En los menús puedes tocar las opciones o usar las flechas y **✓**. Usa **BACK** para volver.

## Controles

Botones grises y translúcidos. Disparo con icono de bala en la parte inferior; granada, cuchillo, recarga e interacción en la columna derecha. Salto arriba y postura abajo.

- **Joystick:** moverte, incluidas las diagonales.
- **Arriba del todo:** activa la carrera automática. Puedes soltar el dedo; toca de nuevo el joystick para detenerte.
- **Zona derecha:** desliza para mirar.
- **Disparo:** mantén pulsado y arrastra para mirar mientras disparas.
- **Mira:** tocar o mantener, según tus ajustes.
- **Mano:** mantener para comprar, abrir o reparar.
- **Granada:** mantener para preparar; soltar para lanzar.
- Botones de recarga, salto, postura, cambio de arma y cuchillo.

Apuntar, disparar, interactuar o abrir el menú cancela la carrera automática. La resistencia sigue siendo la del juego original.

En **Ajustes** puedes cambiar sensibilidad, tamaño, opacidad y posición de los botones, usar la distribución para zurdos y mostrar sus nombres.
